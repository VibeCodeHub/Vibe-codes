R3F Glass Tetris

React + Vite + TypeScript + @react-three/fiber + drei + three.js.

Install

```bash
npm install
```

Run (dev)

```bash
npm run dev
```

Then open the URL printed by Vite.

Build

```bash
npm run build && npm run preview
```

Notes

- TypeScript strict mode enabled.
- Tests will be added in later batches. Use `npm test`.
