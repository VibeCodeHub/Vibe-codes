# PWA Icons

This directory contains icons for the Progressive Web App.

Required icons:
- `icon-192x192.png` - 192x192px icon for Android
- `icon-512x512.png` - 512x512px icon for Android
- `apple-touch-icon.png` - 180x180px icon for iOS (can be same as 192x192)

To generate icons:
1. Create a 512x512px source image with the game logo/icon
2. Resize to 192x192px for `icon-192x192.png`
3. Resize to 180x180px for `apple-touch-icon.png`
4. Use the 512x512px as `icon-512x512.png`

For now, placeholder icons are referenced in the manifest.
